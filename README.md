# Мастерская отличий

Браузерный редактор образовательной игры «Найди отличия» по ТЗ Гальмиз Марии Александровны. Не требует сервера, сборки или npm-зависимостей.

## Запуск

Откройте https://galmizmaria-beep.github.io/otlichi/ после публикации GitHub Pages. Для локального запуска: `python3 -m http.server 8080`, затем http://localhost:8080. Открытие index.html через file:// не поддерживается: редактор загружает игровой модуль для автономного экспорта.

## Создание игры

1. В разделе «Картинки» загрузите A и B.
2. В «Отличия» выберите форму и нажмите «Добавить отличие». Протяните область на одной из картинок. Для многоугольника отметьте вершины и нажмите «Завершить многоугольник».
3. В «Задания» заполните автоматически созданные карточки. Для выбора ответа укажите правильные номера, начиная с 1. Для порядка перечислите элементы в правильной последовательности.
4. Настройте титульный экран, задания, игровую панель, финальные экраны, звуки и объекты. В разделе «Декор» рамки позволяют перемещать и масштабировать объекты; Shift отключает сохранение пропорций.
5. «Тестировать» запускает игру. «Вернуться в редактор» завершает тест без изменения проекта.
6. Сохраните переносимый `.difgame`, скачайте автономный HTML или скопируйте iframe для Genially.


## Обновлённые настройки и библиотека

В «Ассеты» и «Картинки» доступны две созданные ImageGen пары: «Лесная мастерская» и «Рисуем весну». Каждая содержит пять отличий с готовой разметкой и устными заданиями, которые можно заменить. Декоративные PNG/GIF и пять прежних иконок доступны в отдельном разделе «Декор». Файлы и запросы генерации перечислены в [assets/README.md](assets/README.md).

У титульного экрана, победы и поражения настраиваются прозрачность фона, размеры названия и инструкции, надпись кнопки, её ширина/высота, фон, цвет/размер букв, скругление и свечение. Прозрачность относится к фону, текст остаётся читаемым. На экране победы нет кнопки перехода на титульный лист. На экране поражения такой переход остаётся опциональным. Кнопка подсказки имеет собственные настройки цвета и свечения; количество подсказок — от 0 до 999.

Проигрыш наступает только при нуле жизней. Одна оставшаяся жизнь позволяет продолжать и выигрывать. Окончание обратного отсчёта показывает отдельное состояние «Время вышло», сохраняя число оставшихся жизней. Есть восемь встроенных звуков, синтезируемых Web Audio: обнаружение, верный/неверный ответ, потеря жизни, подсказка, победа, поражение, нажатие кнопки. Можно прослушать, заменить или вернуть базовый звук.

Подтверждения удаления и замены проекта показаны внутри редактора; системный диалог с адресом сайта не используется.

## Математика

Формат ввода из предоставленной LaTeX-шпаргалки: `$…$` в строке, `$$…$$` отдельным блоком. Формулы поддерживаются в вопросах, вариантах ответов, элементах порядка и текстах экранов. В разделе «Задания» есть математическая шпаргалка с 30 кнопками вставки. Сначала выберите поле, затем нажмите нужный шаблон.

Для разбора используется локальная копия KaTeX 0.16.22 ([официальный API](https://katex.org/docs/api)); лицензия сохранена в `vendor/KATEX-LICENSE`. Формулы заранее превращаются в MathML при предпросмотре/экспорте, поэтому автономная игра не загружает KaTeX, шрифты или CDN. Невалидная формула остаётся видимой как безопасный текст. Пользовательский HTML экранируется.

## Правила

Победа наступает после успешного выполнения всех заданий при наличии хотя бы одной жизни. Ошибка не завершает отличие: после закрытия задания его можно открыть повторно. Подсказки не завершают задания; скрытые зоны не подсвечиваются. Во время задания таймер может останавливаться. Элементы порядка перемещаются перетаскиванием либо кнопками вверх/вниз.

## Хранение и экспорт

Проект содержит `schemaVersion: 2`, встроенные изображения и звуки. Поддерживается миграция схем 0 и 1 с сохранением настроек и загруженных звуков; неизвестные версии отклоняются. Автосохранение в localStorage зависит от квоты браузера: для больших проектов сохраняйте файл вручную. Undo хранит до 40 снимков, история не входит в экспорт.

Статические картинки сжимаются в Web Worker (в старых браузерах используется Canvas в основном потоке), уменьшаются до 1600 px и сжимаются в WebP с сохранением прозрачности. GIF и звук сохраняются без перекодирования. Максимальный размер отдельного ресурса — 15 МБ, импортируемого проекта — 50 МБ. Предупреждения показывают маленькие / перекрывающиеся зоны, низкий контраст и большой экспорт.

HTML включает игровой модуль, стили и ресурсы. Экспорт не использует GitHub и не меняется после редактирования проекта. «Облегчить для Genially» оптимизирует картинки до 1000 px/WebP, сохраняет GIF, исключает редакторские поля и пакует игру в gzip, если это уменьшает итоговый код. Размер до и после отображается в окне экспорта. Проект остаётся без изменений. Для упакованной версии требуется поддержка DecompressionStream в браузере ученика. Код для Genially — iframe с `srcdoc` и `sandbox="allow-scripts"`. Фактическую вставку нужно проверить в вашем тарифе и редакторе Genially: сервис может фильтровать srcdoc или ограничивать размер кода. В таком случае разместите скачанный HTML на выбранном хостинге и вставьте его URL.

27 языков переводят стандартные игровые кнопки; пользовательские тексты не переводятся. Арабский использует RTL. Список шрифтов включает системные и популярные веб-шрифты; веб-шрифты применяются, только если установлены на устройстве, иначе используется Arial. Внешние шрифты не загружаются автоматически, чтобы HTML оставался автономным.

## Проверки

`node --test tests/*.test.cjs` — геометрия зон, пять типов ответов, соответствие заданий, миграция, экранирование, кнопки панелей, новые настройки экранов, математические формулы, упаковка Genially и игровые сценарии. CI выполняет тесты перед публикацией.

Ручная проверка: загрузка двух изображений, зоны на обеих картинках, все типы заданий, победа с одной жизнью, поражение, штрафы, таймер, восстановление черновика, автономный HTML, GIF и сенсорное управление. Проверка реальной вставки в Genially и совместимости Safari/Firefox требуется отдельно.

## Публикация

Workflow `.github/workflows/pages.yml` публикует сайт при изменении `main`. Если автоматическое включение Pages не разрешено аккаунтом, выберите **Settings → Pages → Source: GitHub Actions** и запустите workflow **Publish editor**.

## Архитектура

- `js/core.js`: модель, миграция, валидация, проверка ответов и геометрия.
- `js/game.js`: один runtime для теста и автономного экспорта.
- `js/editor.js`: панели, импорт ресурсов, разметка, история, сохранение и экспорт.
- `style.css`: адаптивный интерфейс редактора.

Известные ограничения относительно расширенного ТЗ: встроенные дополнительные web-шрифты, свободная трансформация заголовков/картинок и полноценные направляющие не реализованы. Панель HUD позиционируется настройками; объекты ассетов поддерживают перетаскивание, размер, сетку, центрирование, слои и блокировку. Локальные ресурсы и стандартные шрифты позволяют использовать игру без сети.
